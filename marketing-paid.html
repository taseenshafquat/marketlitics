HOW TO ADD RESULTS

Few Blocks, Same Names Every Time

3 blocks per campaign, in the centre slider. If you have more PDF pages, add a 4th file name in the images line below, in the script, and a 4th dot appears on its own.

STEP 1

Export The PDF Pages

Open your results PDF, export or screenshot each page as a JPG. Keep the order, page 1 first.

STEP 2

Name Them Exactly

Aqtiv: aqtiv-result-1.jpg, aqtiv-result-2.jpg, aqtiv-result-3.jpg. Campaign 2: campaign-2-result-1.jpg, and so on. Same folder as this HTML file.

STEP 3

Upload With The File

Upload the JPGs to Vercel with marketing-paid.html, same folder, same names. No code change, the viewer finds them.
